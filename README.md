# Mochi

Mochi 是一个本地优先的个人工作台，用于记录学习、整理知识、管理资料、规划日程，并让 AI 自然参与到您的日常工作中。

在 Mochi 中，一个本地文件夹就是一个工作区。笔记、表格、图片、附件、日程和 AI 会话都围绕工作区保存与组织；您可以按学习、工作、项目、日志等不同用途建立多个工作区。

## 轻量原生桌面版

Mochi 提供 Rust 原生 Windows 桌面版。

它直接使用 Win32、Direct2D 和 DirectWrite 绘制界面，尽可能地以较低的基础内存占用运行。


## 开始使用

安装并打开 Mochi 后，选择一个已有文件夹，或新建一个文件夹作为工作区。之后可以直接在左侧目录树中创建文件夹、文档、多维表格和画布。

推荐的起步方式：

1. 新建一个知识库工作区。
2. 用“小记”或收件箱快速记录想法。
3. 用文档沉淀完整内容，用多维表格管理任务与资料。
4. 在日程中安排待办和复习。
5. 将文档、图片、表格单元格发送给 AI，进行阅读、整理与辅助创作。

## 本地工作区与知识库

知识库是 Mochi 的基础单位。每个知识库对应一个本地目录，目录内的文件、附件和应用数据共同组成您的个人知识空间。

- 文档直接保存在本地，方便备份、迁移和自行管理。
- 可以按主题建立文件夹，例如“学习笔记”“工作资料”“项目文档”“个人日志”。
- 左侧目录树会展示文件夹层级，支持新建、重命名、移动、复制、删除、搜索和在资源管理器中显示。
- 支持将常用文件加入收藏；收藏页可只显示收藏文件，也可以保留原有父级目录结构。
- 最近页面会汇总最近打开和编辑的内容，方便继续上一次的工作。
- 可使用 Git 管理工作区历史版本，适合对重要内容自行留存版本记录。

## 首页与仪表盘

首页用于快速了解当前工作状态，并直接进入常用内容。

- 最近笔记与收藏文档
- 收件箱中的待整理内容
- 最近 AI 会话
- 今日日程、待办与日记入口
- 知识图谱预览
- 写作、学习与活动统计

当您不知道从哪里开始时，首页会把当天最需要处理的内容集中展示出来。

## 文档

Mochi 支持 Markdown、Mochi 文档和普通文本文件，适合从快速记录到长期知识沉淀的不同场景。

### Mochi 文档

Mochi 文档使用 `.mc` 格式，以块组织内容。它适合需要更丰富排版和结构化编辑的笔记。

可根据习惯切换编辑方式：

- **所见即所得模式**：直接看到最终排版效果，适合日常写作、阅读和快速整理。
- **源码模式**：集中编辑完整源内容，适合熟悉 Markdown、连续写作、批量调整或内容迁移。
- **块源码模式**：以内容块为单位查看和编辑源码，兼顾局部精确修改与整体可视化阅读。

### Markdown 与纯净文档模式

如果您更习惯原生 Markdown，可以在设置中开启纯净文档模式。开启后，新建文档默认保存为 `.md`，并使用更贴近 Markdown 的编辑体验，便于与其他 Markdown 工具协作。

### 编辑与排版

文档支持常见的写作与知识整理元素：

- 多级标题、段落、分隔线与引用
- 无序列表、有序列表与待办清单
- 加粗、斜体、下划线、删除线与行内代码
- 代码块、表格、数学公式与链接
- 图片插入、文件引用与网页链接
- 文档大纲、查找替换与撤销恢复

右侧面板可查看大纲、链接、属性，以及插件提供的辅助功能。

## 多维表格

多维表格使用 `.mcb` 文件保存，适合管理任务、学习计划、书籍、课程、资料、项目、联系人和其他结构化数据。文档用于记录完整思考，多维表格用于提取重点、统一查询和跟踪进度。

### 字段类型

可按需要建立不同字段：

- 文本、数字与复选框
- 单选、多选与彩色标签
- 链接与进度
- 日期、时间点与时间范围
- 引用与文档关联

### 视图与整理

- 表格视图：适合逐行查看和编辑数据。
- 看板视图：适合按标签或状态分组推进任务。
- 支持筛选、排序、分组、搜索和行高调整。
- 表格默认进入编辑模式；可在设置中改为默认查看模式。
- 下拉菜单点击空白处即可关闭。

### 快速操作

- 右键单元格可向上、向下新增记录，向左、向右新增字段。
- 可新建表格专用临时文档，用于记录与当前表格相关的草稿或补充内容；临时文档默认不显示在目录树中。
- 右键单元格可发送给 AI，AI 会获得字段、当前值与同一记录的相关信息。
- 熟练度、进度等数值可通过拖动条和小输入框调整。
- 时间点使用年、月、日、时、分选择器；打开后默认当前时刻，直接点击确定即可写入当前时间。

## 文件、资料与画布

Mochi 不只管理文字笔记，也可以把资料与知识对象放在同一工作区中。

- 支持图片、PDF、Office 文档、代码文件、网页链接和普通附件。
- 可预览支持的文件，并在文档、表格和 AI 会话中引用它们。
- 画布使用 `.mcanvas` 文件保存，可将文档、记录、任务、日程和 PDF 批注作为卡片自由排列。
- 画布中的卡片保存的是原对象引用，不会复制一份内容；原文更新后仍可通过卡片回到对应对象。
- PDF 批注可以作为可追溯的知识对象加入工作流。

## 收件箱与小记

小记适合记录暂时不需要分类的灵感、会议要点、待办或学习问题。记录完成后可以直接存入收件箱，再决定是否整理为文档、任务、日程或表格记录。

收件箱集中展示：

- 尚未整理的快速记录
- 待处理的文件或内容操作
- AI 生成、等待您批准的修改建议
- 需要稍后继续处理的事项

这样您可以先捕获信息，再在合适的时间进行整理，而不必在记录当下决定最终位置。

## 日程、任务与复习

日程模块用于把知识管理落到行动上。

- 创建任务、日程、项目和学习计划。
- 查看今日安排、待办、完成情况与时间节点。
- 管理学习时间、复习安排、熟练度、错题和知识点进度。
- 使用不同日程视图查看计划与推进状态。
- 可以让 AI 根据您的目标创建或整理日程变更；自动执行与待批准模式可在设置中选择。

适合的使用方式包括：为课程建立复习节奏、追踪刷题进度、安排项目里程碑，或把会议记录转换为可执行任务。

## AI 助手

Mochi AI 可以读取、整理和辅助处理工作区中的信息。首次使用前，请在设置中配置兼容的第三方 AI 服务。

### 对话与上下文

- 支持多轮对话、会话历史与会话搜索。
- 可将当前文档、文本选区、文件、图片或多维表格单元格发送给 AI。
- 文档会以附件卡片显示，图片会以缩略图显示；发送前可移除不需要的上下文。
- 可以把文档挂载到会话，持续围绕同一主题讨论。
- AI 可以结合知识库、日程和表格中的信息回答问题。

### Agent 与自动化能力

- 支持自定义 Agent、提示词模板和 Skills。
- 可让 Agent 协助阅读文档、提炼大纲、改写内容、创建任务、整理资料或生成表格。
- 支持工具调用，用于在授权范围内读取和操作 Mochi 中的对象。
- 可以为文件或目录设置 AI 权限；不希望 AI 读取的内容可设为不可见。

### 修改建议与审批

涉及文件、日程、命令或插件的操作会以卡片形式展示状态。您可以查看内容、批准、拒绝或保留待后续处理。这样 AI 可以参与工作流，同时由您保留最终控制权。

## 知识图谱、链接与搜索

Mochi 通过链接和对象引用把分散内容组织成网络。

- 使用文档链接在笔记之间建立关联。
- 使用 Mochi 对象链接定位到文档、块、表格记录、任务、日程、AI 会话或 PDF 批注。
- 知识图谱帮助浏览知识对象之间的关系。
- 全文搜索适合跨工作区内容快速查找。
- 命令面板和快速打开可直接跳转到文件、页面或常用操作。

## 模板、Agent 配置与插件

### 模板中心

模板中心用于新建、管理和复用文档模板。您可以为学习笔记、会议记录、读书笔记、日报、项目复盘等重复场景建立模板，也可以把任意已有文档另存为模板。

### Agent 配置

Agent 配置用于管理不同 AI 角色。例如，可以为“学习助手”“写作助手”“项目助理”分别设置名称、提示词和工作方式。

### 插件

插件可以扩展导航栏、侧边栏、编辑器工具栏、右侧面板和独立工作区页面。您可以在设置中查看、安装、启用或管理插件。

## 外观、设置与个性化

Mochi 将常用体验选项开放在设置中，方便按自己的习惯调整。

- 主题、深色模式、界面颜色、字体、字号和背景图片
- 编辑器行为、行宽、自动保存和文档显示方式
- 目录树图标、层级引导线、隐藏名单与文件扩展名显示
- 默认文档格式、默认表格模式与表格显示方式
- 快捷键、AI 服务、Agent、日程执行方式和插件

部分设置在重新打开应用后生效。

## 典型使用方式

### 学习管理

用文档记录课程内容和思考，用多维表格建立知识点、题目、熟练度和复习时间，用日程安排每日学习与复盘。需要总结时，将文档或表格单元格发送给 AI。

### 项目管理

为项目建立知识库，用文件夹存放需求、会议记录和方案文档；用多维表格或看板跟踪任务状态；用日程安排里程碑；将会议记录发送给 AI，整理为任务清单。

### 个人知识库

将阅读笔记、网页资料、PDF 批注和图片统一放入知识库。用链接、收藏和知识图谱连接主题，用模板保持记录结构一致，用搜索快速回到过去的内容。

### 快速捕获与后续整理

想到什么先写入小记或收件箱。之后再补充为文档、加入表格、创建任务，或让 AI 协助归类和改写。

## 数据与更新

您的内容保存在本地工作区中。请定期备份重要工作区；如使用 Git，可按自己的习惯保留版本历史。

在“设置 → 通用 → 检查更新”中可以下载并安装新版本。
